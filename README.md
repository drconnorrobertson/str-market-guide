# STR Market Guide

A production-ready, mobile-first web edition of the BNB Accelerator short-term-rental market guide for 2026.

## What is included

- Editorial homepage and book-style guide
- Searchable, filterable market watchlist
- SEO titles, descriptions, canonical URLs and structured data
- `robots.txt` and XML sitemap
- Accessible navigation, responsive layouts and reduced-motion support
- Vercel configuration for a zero-build static deployment
- Lead-capture user interface ready to connect to an email or CRM platform

## Local preview

Serve the `dist` directory with any static web server. The production output is already built.

## Vercel

Import the GitHub repository into Vercel. The included `vercel.json` points Vercel at `dist`; no build command or framework preset is required.

Recommended production domain: `strmarketguide.com`.

## Launch checklist

1. Connect the lead form to the preferred email/CRM endpoint.
2. Purchase and attach the custom domain.
3. Replace canonical and sitemap URLs only if a different domain is selected.
4. Verify the domain in Google Search Console and submit `/sitemap.xml`.
5. Submit priority URLs to IndexNow after the domain is live.

Market information is educational and intentionally avoids unverified performance promises. Regulations, taxes and economics should be refreshed against official sources before publication updates.
